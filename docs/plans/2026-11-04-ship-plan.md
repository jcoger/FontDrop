# FontDrop Mac app: ship plan

> Superseded by `2026-11-05-ship-plan.md`.

2026-11-04. Written so you can pick it up and go. Every round has a done check that something outside the model verifies.

## What "shipped" means

**v1.0 is a signed, notarized Mac app** that a designer downloads from GitHub Releases, opens without a warning, and uses to:
1. pick a Display face from their own library;
2. find and compare Reading faces for it, either way round;
3. set sizes and spacing;
4. hand off the pair: a spec page, CSS/Tailwind/Paper tokens, and a license list.

The repo is public and `main` holds the Mac app.

**Not in v1:** Brand Colors, the UI and Mono jobs, "Like my picks", the Claude connector, bring-your-own-key AI, and the glyph tells strip. All of these have notes and come after.

## Rounds

Each round is one builder run plus my review and screenshots against Paper. The sizes are rough: S is a few hours, M is a day of agent time.

### R0. Review fixes (running now)
Database safety, rescan speed, Reading rules that agree, variable fonts in Reading, robustness, scan status in the sidebar.
**Done:** the core and app test suites pass. On a library copy, there are 0 duplicate rows, the rescan is measurably faster, and more variable families reach Reading.

### R1. Either way in (M)
After a Reading face is chosen, Display ranks headline faces against it: a "Pairs with <Reading>" sort, reason lines on cards, and evidence worded by role. Check that the engine's scoring isn't one-way.
**Done:** a cold walkthrough that starts from a body face finishes with no stuck points.

### R2. Simplify (M)
From the UX audit (`docs/ux/2026-10-22-mac-app-ux-audit.md`, S1 to S8, C2, C4, U2, U5):
- one "keep" idea per screen;
- the Display filter bar on one row (a scope menu, a kind control, and More);
- the "Display" kind chip becomes "Decorative";
- stars only on hover or when saved;
- cut every roadmap placeholder;
- stylistic sets as glyph tiles;
- no auto-select on first run;
- the grid shows default styles, with a "Tuned" mark.

Engine: fix the serif detector reading PP Neue Machina as a serif, and map vendor IDs to real foundries.
**Done:** a before-and-after count of controls on each screen. The Machina and foundry spot checks pass.

### R3. Set (M)
The real Set screen:
- a type scale for the pair (from the type-set skill's scale rules);
- line length and line height for body;
- optical size and STYL axes where the face has them;
- a live specimen in the stage pattern.

The inspector holds the controls.
**Done:** Set renders the brand's pair at every scale step with no clipping at 1000, 1360 and 1728. Values persist per brand.

### R4. Hand-off v1 (M)
Export replaces the disabled button:
- a one-page pair spec (PNG and PDF) with the pair, scale, tuning and colors;
- CSS variables and a Tailwind theme on the clipboard;
- a Paper spec;
- a license list: each face, its foundry link, trial flagged with "license before you ship".

**Done:** the cold walkthrough's task 6 ("what do I take to my client and into my file?") passes. The exported CSS renders the same pair in a browser.

### R5. Mac behaviour (S to M)
From the audit, section 5:
- **Keyboard:** arrow-key selection in the grid and list, Return to Use, Space for a big preview, ⌘F to search, ⌘1 to ⌘3 for the steps, ⌘+ and ⌘− for zoom, ⌘Z to undo a choice.
- **Menus:** the commands appear in the menu bar.
- **Sample text:** type your own sample on Display.
- **Sliders:** editable number fields with steppers.

**Done:** every core task can be done from the keyboard alone, and the menus list their shortcuts.

### R6. Ship (S, after D1, D2, D5, D6)
- the rename PR, if D1 clears;
- app icon;
- About window and version;
- crash-safe first launch on an empty library;
- Developer ID signing, hardened runtime, notarization and a stapled DMG, all through one `make release` script;
- a GitHub Release with notes;
- the README install section;
- delete Tauri (D5);
- merge the stack (D6).

**Done:** a fresh macOS user account downloads the DMG, opens it with no Gatekeeper warning, scans its fonts and completes the six tasks.
