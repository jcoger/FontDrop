# FontDrop Mac app: ship plan, v2

2026-11-05. Replaces `2026-11-04-ship-plan.md`. It folds in the design review (Paper page "Design review · Nov 4", boards 13 to 19), the UI critique, and the IA audit (`docs/ia/2026-11-05-fontdrop-ia-spec.md`). Every round has a done check that something outside the model verifies.

## What "shipped" means

**v1.0 is a signed, notarized Mac app** that a designer downloads from GitHub Releases, opens without a warning, and uses to:
1. pick a Display face from their own library;
2. find and compare Text faces for it, either way round;
3. set sizes and spacing in Set;
4. export the pair: a spec page, CSS, Tailwind and Paper tokens, and a license list.

The repo is public and `main` holds the Mac app.

**Not in v1:** a third face, Brand Colors as a sidebar row, Like my picks, the Claude connector, bring-your-own-key AI. Notes for each are under "After v1".

## Rounds

Each round is one builder run, then my review and screenshots against the Paper boards. S is a few hours of agent time, M is about a day.

### R1. Names and structure (S)
- Rename the Reading job to **Text** in every UI string (17 today), help text, VoiceOver labels and menus. The code's internal `reading` name can stay.
- Make the sidebar Brand switcher · Display · Text · Set. Hide UI and Mono. Remove the Saved and Colors rows; Saved stays a filter in the Display filter bar.
- Rename the scale mode to Auto, "Letters and spacing" to "Spacing and features", "Chosen" to "Current", and the Hand off button to Export.
- Remove the Shortlist section from the Text inspector (the lexicon already cut it).
- Cut roadmap text: "Coming next", "Nothing to inspect yet", "Colors · Parked".
- ⌘1 to ⌘3 for Display, Text, Set.

**Done:** a grep finds no UI string "Reading", "Chosen", "Hand off" or scale-mode "Fit". The sidebar matches board 17. A first-click test of "Text" and "Auto" with 3 designers (where would you set a poster's credit line? how do you undo a locked scale?): 3 of 3 right.

### R2. The look (M)
Tokens first, then components. Built once, recoloured per theme.
- **Tokens:** glass rim, fill ladder (page → panel → control → screen), text and secondary text at 4.5:1 or better in both themes, one red.
- **Selection:** the inset pill in the list and the sidebar. A separate focus-visible ring.
- **Screens:** recessed fill with a top inner shadow. Doto readouts at one size.
- **Icons:** SF Symbols in one weight. Drawn chevrons for menus and pop-up buttons.
- **Dial:** in Set's inspector, five stops, glow by state (Auto none, Locked soft, Turning bright), a trackpad click per stop, arrow keys, VoiceOver value, Increase Contrast drops the glow, Reduce Motion skips the spring.
- **Text screen:** a one-line scale readout that opens Set.
- **Letters strip:** Il1, ag, RGQ, 0O tiles in the Text inspector.
- **Dark grain:** a tiled noise texture at about 7% on dark panels only. Never on the stage or a specimen.

**Done:** app screenshots of the Text screen in both themes match boards 17 and 18, side by side. Contrast script passes every text pair. The dial's states are checked with a VoiceOver walk.

### R3. Either way in (M)
After a Text face is chosen, Display ranks headline faces against it: a "Pairs with <Text face>" sort, reason lines, evidence worded by role. Includes D7.
**Done:** a cold walkthrough that starts from a body face finishes with no stuck points.

### R4. Simplify (M)
UX audit S1 to S8, C2, C4, U2, U5: one "keep" idea per screen, the Display filter bar on one row, the "Display" kind chip becomes "Decorative", stars on hover or when saved, stylistic sets as glyph tiles, no auto-select on first run. Engine: the serif detector misreads PP Neue Machina; map vendor IDs to real foundries.
**Done:** a before and after count of controls per screen. The Machina and foundry spot checks pass.

### R5. Set (M)
- The real Set screen: a type scale for the pair, line length and line height for body, optical size and STYL axes where the face has them, a live specimen.
- The dial, Body and Lock live in its inspector, in the instrument look.
- Move Scale, Colors and face settings out of the three JSON files into the database. Then brand delete can ship safely.

**Done:** Set renders the pair at every scale step with no clipping at 1000, 1360 and 1728 px. Values persist per brand in the database. Deleting and recreating a brand starts clean.

### R6. Export (M)
- One-page pair spec (PNG and PDF).
- CSS variables and a Tailwind theme to the clipboard.
- A Paper spec.
- A license list: each face, its foundry link, trials flagged "license before you ship".

**Done:** the walkthrough task "what do I take to my client and into my file?" passes. The exported CSS renders the same pair in a browser.

### R7. Mac behaviour and ship (M)
- Keyboard for every core task, menus that list their shortcuts, your own sample text on Display, number fields with steppers on sliders.
- Fix the screenshot flags that hang the app (`--lock`, `--inspector`, `--compare`).
- The rename PR if D1 clears, app icon, About window, crash-safe first launch.
- Developer ID signing, hardened runtime, notarization and a stapled DMG through one `make release` script.
- GitHub Release notes, README install section, delete Tauri (D5), merge the stack (D6).

**Done:** a fresh macOS user account downloads the DMG, opens it with no Gatekeeper warning, scans its fonts and completes the six walkthrough tasks.

## Order
R1 → R2 and R3 in parallel (R2 is chrome and tokens, R3 is engine and Display) → R4 → R5 → R6 → R7. D1 and D2 paperwork can start today.

## After v1
- **A third face.** One optional "+ Add a face" row replaces the hidden UI and Mono rows. You pick its job: Accent (quotes, eyebrows, a script), Labels (interface text) or Mono (code, data). The engine ranks it by its weaker match against Display and Text, plus a check that it is not a near-copy of either. Each template gets a slot for it that falls back to Display or Text when empty. Export adds one token.
- **Swap on the template.** Hover a text block on the stage to see which face and job set it, then swap: flip through the shortlist for that job right there, with the change animating in place. Pairs well with the third face, since it shows which block each face owns.
- Like my picks, the Claude connector, search by look and meaning, pressure checks from the type-set skill, Send to Paper, a "tells apart" mark on the glyph strip.
